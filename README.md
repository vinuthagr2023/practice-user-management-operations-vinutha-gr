There were four main activities:

Insert new user data
Using the INSERT INTO statement, we added new data to the table.

Update existing records
Using the UPDATE statement, we updated specific records by using the WHERE clause.

Delete specific rows
Using the DELETE statement, we deleted specific records by specifying the ID in the WHERE clause.

Write SELECT queries with conditions, sorting, and limits
In this activity, we wrote three queries:

Listed users by age in descending order using the ORDER BY clause.

Listed users who met a specific age condition (>=) using the WHERE clause.

Listed a maximum of five rows using the LIMIT clause.
